## The line

> My doctor told me to drink more water, so I cry eight glasses a day.

68 characters, one line, one breath. The laugh comes from the line itself:
the twist lands on the last words — crying as hydration, eight glasses
a day, exactly what the doctor ordered. Fresh wording, plain speech,
no meme, no explanation, no shared knowledge needed.

## How it works

`main.py` (Python 3 stdlib only, no network) writes the line to
`/output/entry.txt`, exactly 68 characters, no trailing newline.
It validates the 1–140 character gate before writing.

## Run it

```sh
python3 main.py
# or: MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
